# Career Gate branding

Source assets taken from the Career Gate Facebook page (facebook.com/Careergateegypt).

## Colors

| Name         | Hex       | Use                                   |
|--------------|-----------|---------------------------------------|
| Yellow       | `#FEC401` | Main brand color, headers, highlights |
| Yellow light | `#FFF3C4` | Hover states, selected rows           |
| Navy         | `#141F2D` | Logo, text, menu bar, primary buttons |
| Navy light   | `#24344A` | Hover on navy buttons                 |
| White        | `#FFFFFF` | Page backgrounds, door in the logo    |

## Files

* `careergate-logo.png`, `careergate-cover.png`, `careergate-hiring-post-sample.png`: originals.
* `../src/images/logo.png`: cropped logo used in the app.
* `../src/images/icon-*.png`: door mark used as the window icon (16 to 256 px).
* `../src/images/banner.png`: cover photo used on the home screen.
* `screenshots/`: how each window looks with the branding applied.

## In code

All colors, fonts, the logo, the window icon, the header band and the button styles
come from `src/Branding.java`. Change them there and every window follows.
