# Standard operating procedures

One guide per role, in English and Arabic. The same text is shown in the app: every user opens it from the settings menu, Help.
Edit `scripts/sop/content.py`, then run `python3 scripts/sop/build.py` to update the app and these files.

- [Dark store staff](store_staff.md): Receivers, pickers and packers working inside a dark store or the hub. Open your store from the home screen.
- [Rider](rider.md): Riders delivering 60 minute orders from a dark store.
- [Merchant](merchant.md): Shops selling through Shiply Now 60 minute delivery.
- [Finance](finance.md): The finance team and the accountant. Everything is in /finance.
- [Admin](admin.md): Operations admins. You can open every area.
