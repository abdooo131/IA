The four rules that matter most

1. Sky is a fill, never text. Shiply Sky #59CBE8 has about 1.9 to 1 contrast on white. Use it only for backgrounds and fills. Never for text, thin lines or outline icons on white. Text on Sky is Navy or Blue.
2. Status = color + icon + label. Every order status always shows its color, its own icon and its label together. Never color alone. In sunlight, violet and magenta look alike; the icon is what couriers read.
3. Wallet colors stay in the wallet. COD cash (teal) and driver points (sun yellow) appear only in wallet cards, balances and transactions. Never in status chips.
4. One Blue button per screen. The primary action is Shiply Blue with white text. Everything else is secondary or outline.

07

Logo and app icons in the product

Header logo

Dashboard header and login: logo-horizontal-primary.svg, 28 px tall. On Blue or in dark mode: logo-horizontal-reverse.svg. Never below 24 px tall; below that use the icon.

App icon

iOS: app-icon/ios/AppIcon-1024.png (square, iOS rounds it). Android adaptive: foreground from app-icon/android, background color #0047BB. Web: favicon.svg plus PNG sizes, theme color #0047BB.

Don't

  • Recolor, stretch, rotate or add effects to the logo.
  • Retype "shiply" in a font; always use the files.
  • Place the primary logo on Blue or dark backgrounds; use the reverse version.
08

Dark mode, Arabic and accessibility

Dark mode

  • Switch the role tokens (light to dark column). Brand Blue #0047BB is too dark on Navy, so dark mode uses #2F6BFF for buttons and #5B8CFF for links and selected states.
  • Sky stays #59CBE8. Status and wallet colors use their lighter dark values. Tints become 12 to 14% of the color over the surface.
  • Follow the device setting by default, with a manual switch in settings (Light, Dark, System).

Arabic and RTL

  • Set dir="rtl" and mirror the whole layout: sidebar on the right, back arrows point right, progress fills from right to left.
  • Keep numbers, order IDs (SHP 1048 8203 77), phone numbers and amounts left to right inside RTL text.
  • Arabic labels for statuses are in section 02. Use simple Egyptian Arabic, as in the brand book.

Accessibility

  • Body text at least 4.5 to 1 contrast, large text and icons at least 3 to 1. All role pairs in this spec pass.
  • Never communicate with color alone (status rule). Focus ring always visible on keyboard focus.
  • Minimum text size 12 px on web, 11 sp in apps.
09

Change checklist

The list of edits to bring the current system in line with the brand.

  1. Install the fonts and set Plus Jakarta Sans as the default UI font, IBM Plex Sans Arabic for Arabic.
  2. Import the tokens for your platform and replace hard-coded colors with role tokens.
  3. Replace the logo in headers, login, emails and PDFs with the files in /logo.
  4. Update app icons, favicon and store listings from /app-icon.
  5. Replace UI icons with the Shiply set; apply the selected state in navigation and tabs.
  6. Map every order status to the new color, icon and label (section 02). Show all three in chips and filters.
  7. Restyle stat cards with the 4px status strip.
  8. Add the wallet colors to COD cash and driver points cards and transactions.
  9. Restyle buttons, inputs, alerts and navigation per section 05. One primary button per screen.
  10. Add dark mode with a Light, Dark, System switch.
  11. Check every screen in Arabic RTL.
  12. Run a contrast check: no Sky text or thin Sky lines on white anywhere.
