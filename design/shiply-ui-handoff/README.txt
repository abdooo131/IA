SHIPLY UI HANDOFF v1.0

Start with Shiply-UI-Spec.pdf (or open Shiply-UI-Spec.html in a browser).
It explains every token, component and rule, and ends with a checklist of the changes to make.

tokens/     CSS (light + dark), Tailwind preset, JSON, Flutter, Android XML, iOS SwiftUI
fonts/      Plus Jakarta Sans (TTF + WOFF2) and IBM Plex Sans Arabic (TTF), SIL Open Font License
icons/      34 icons as SVG: outline, selected, currentColor, plus one sprite file
logo/       Logos with outlined letters, SVG and PNG, four colorways
app-icon/   iOS, Android adaptive, Play Store, favicons and PWA icons

The four rules:
1. Shiply Sky (#59CBE8) is a fill or background only. Never text or thin lines on white.
2. Every order status shows its color, its icon and its label together.
3. Wallet colors (COD cash teal, driver points yellow) only inside the wallet.
4. One Shiply Blue button per screen.
